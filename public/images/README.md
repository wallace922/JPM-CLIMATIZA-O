# Guia de Imagens — JPM Climatização

Esta pasta contém todas as imagens utilizadas na landing page da JPM Climatização.

## Estrutura de Pastas e Arquivos

```
public/images/
├── logo/
│   └── logo.png              # Logotipo principal da marca (Recomendado: PNG transparente 500x500px ou SVG)
├── sobre/
│   └── equipe.png            # Foto da equipe / técnico responsável (Recomendado: JPG/PNG 800x600px)
├── trabalhos/
│   ├── trabalho-1.png        # Projeto 1: Instalação Residencial Split Inverter (Recomendado: 800x600px)
│   ├── trabalho-2.png        # Projeto 2: Manutenção Preventiva Comercial (Recomendado: 800x600px)
│   ├── trabalho-3.png        # Projeto 3: Sistema VRF Multi-Ambiente (Recomendado: 800x600px)
│   ├── trabalho-4.png        # Projeto 4: Conserto de Refrigeração Comercial (Recomendado: 800x600px)
│   ├── trabalho-5.png        # Projeto 5: Limpeza Técnica e Troca de Filtros (Recomendado: 800x600px)
│   └── trabalho-6.png        # Projeto 6: Climatização Comercial de Teto (Recomendado: 800x600px)
└── README.md
```

## Como Substituir pelas Suas Imagens Reais

1. Para alterar a foto da **Equipe / Sobre**:
   - Substitua o arquivo em `public/images/sobre/equipe.png` por sua nova imagem com o mesmo nome.

2. Para alterar as fotos da **Galeria de Trabalhos**:
   - Substitua os arquivos `trabalho-1.png` até `trabalho-6.png` na pasta `public/images/trabalhos/`.

3. Para alterar o **Logotipo**:
   - Substitua o arquivo em `public/images/logo/logo.png`.

> 💡 **Dica de Desempenho**: Mantenha as imagens otimizadas (em formato WebP, PNG comprimido ou JPG) para garantir carregamento ultra-rápido no site.
